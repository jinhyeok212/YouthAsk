# RAG 1차 비교 실험 — 현수 담당 최종 정리

## 1. 결론

- 현수 담당 검증 결과: **PASS (19/19)**
- Baseline, C01, C02, C03 모두 47개 질문의 Top-5 순위·청크 ID·검색시간이 정상 저장됐다.
- 각 조건 R2~R4에서 검색 순위 불일치는 0건이고 실행 오류도 0건이다.
- 속도 대표값은 R2~R4 지표의 중앙값이다.
- C01이 평균 345.042ms로 가장 빨랐고 문서·청크 검색 지표도 가장 높았다.
- C03은 p95 489.204ms로 C01과 비슷하며 Baseline보다 37.26% 짧았다.
