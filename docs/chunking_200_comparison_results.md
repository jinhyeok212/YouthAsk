## 선택한 청킹 — M01

선정 원본: **C01 / exp_full_kure_200_fixed_800_ov120_v1**. 확인 실행: **exp_full_kure_200_fixed_800_ov120_v2**.

선정 순서: 문서 Hit@5 → 문서 MRR@5 → 문서 Hit@1 → 같은197문항/필수사실의 Context Recall. 속도나 Baseline과 검수범위가 조금 다른 Context Precision으로 선택하지 않았다.

이 설정은 모델 비교 단계의 기준 후보이며, 답변 품질까지 확인한 최종 설정 채택이 아니다. 성공1문항 차이(0.005)는 작은 차이로 해석한다.

## 비교 시 반드시 기록할 제약

- 문서·질문·Document qrels·691개 필수사실·KURE revision·임베딩차원/정규화/batch·Top5/cosine·오류정책은 고정했다. 변경된 설정 필드는 C01/C02/C03_preflight.json에 기록했다.
- 청킹마다 ID가 달라 qrels와 사실–청크 연결은 별도로 검수했다. Gold 문서 소속이라는 이유만으로 모든 청크를 정답 처리하지 않았다.
- C01/C02/C03은 같은 '완전한 필수사실 포함' 규칙을 쓴다. B01의과거211개검수본은보존했고, 빠진2개를보완한213개공통규칙정답으로원본검색순위를보조재평가했다. 새실험조건을바꾸거나검색을재실행한것은아니다. 원본값과보조평가값을구분해기록한다.
- fixed는 원문 전체를800자로 나누고 section은 본문제한 뒤 정책명 접두어를 붙인다. 이를 변경하지 않았으므로 헤더/입력구성까지 포함한 청킹 비교다.
- Recall은 원문문제로197/200 부분 평가다. 해당3문항/미검수 사실을0점으로 바꾸거나 승인된부분만 분모로 삼지 않았다.
- 온전한 사실을 담는 단일 청크가 없으면 null로 기록하고 분모를 유지했다. C02의0121근로계약/근무/급여조건은 경계에서 나뉘어 이 경우에 해당한다.
- 별도 워밍업없는1회측정이므로 시간은 참고값이며 속도우열을 확정하지 않는다. Index생성은 모델로딩이후 임베딩/DB적재/검증시간이다.

진혁은1번 실행목록과2번비교제약·8-2임시선정근거를 기입한다. 예지는각결과 metrics_summary.json/metrics_by_query.jsonl/failure_cases.csv로3번과6번을 확인한다. 상준은청크Manifest와조건별chunk_fact_map/qrels 및C*_chunk_review.csv, 종선은고정required_facts와3개보류원문을 확인한다. 찬진은experiment_manifest의Index생성/재사용과실제DB용량, 현수는retrieval_results의시간원본을 확인한다.

## 가볍게 검수할 항목

- [공용 비교표](shared_experiment_comparison.md)에 기존2행을 보존하고 실제 실행4행을 추가했다. [질문별 개선·악화 CSV](../experiments/chunking_comparison_eval_200_v1/query_improvement_decline.csv)에서 C01의 `document` 성공 전환4건과 신규 실패3건을 함께 확인한다. 평균 향상이 모든 질문의 향상을 뜻하지 않는다.
- C01은 문서 Hit@5 우선 기준으로 선택했다. C02는 문서 Hit@1과 MRR이 더 높으므로 첫 순위 정확도를 우선한다면 결론이 달라질 수 있다. 선택 조건은 다음 모델 비교용 잠정 기준이다.
- [C01 청크 검수표](../experiments/chunking_comparison_eval_200_v1/C01_chunk_review.csv), [C02 청크 검수표](../experiments/chunking_comparison_eval_200_v1/C02_chunk_review.csv), [C03 청크 검수표](../experiments/chunking_comparison_eval_200_v1/C03_chunk_review.csv)에서 실제 원문 사실·청크 본문·포함 이유를 확인한다. 이는 사용자가 위임한 검수이며 사람이 승인한 것으로 표시하지 않는다.
- 기존 B01에서 공통 규칙으로 추가된 정답2개는 new0039의 신청방법 청크(서식·자기소개)와 new0054의 신청방법 청크(계획서·사업·세금)다. [보조 평가 Manifest](../experiments/chunking_comparison_eval_200_v1/baseline_common_gold_evaluation/evaluation_manifest.json)와 그 폴더의 qrels_chunk.jsonl에서 확인한다. 원래 B01 정답·결과는 보존했다.
- C02의 new0121은 근무시간·급여·예외 조건을 함께 담은 사실이 청크 경계에서 나뉜다. 없는 정답을 만들지 않고 해당 fact의 null 연결과 Recall 분모를 유지했다.

## 최종 검증 및 변경 파일

[최종 검증 보고서](../experiments/chunking_comparison_eval_200_v1/final_verification.json): 기존 파일28개 SHA256 보존, 4개 실행 SUCCESS·오류0, 설정/문서/Gold/Context 입력 검증 통과. fixed v1·v2의200문항 Top-5 결과와 점수가 동일하다. 테스트175개 통과. Recall은 같은3문항이 보류되어197/200 부분 평가다.

이번 작업은 새 YAML4개, 조건별 청크·Manifest·정답·사실 매핑·검수 CSV3세트, Index3개, 실제 실행 결과4폴더, 비교·선정·검증 자료를 추가했다. 준비/보조 재평가/선정·보고/공용표 반영/최종 검증 스크립트와 청킹 비교 테스트를 추가했다. AGENTS.md와 공용 비교표를 갱신했다. 기존 Runner·청킹 알고리즘·모델 설정과 기존 완료 실행은 수정하지 않았다.
